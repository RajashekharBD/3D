# ABSTRACT

This project presents the design and development of an automated end-to-end pipeline that converts a single 2D RGB image into a high-fidelity textured 3D mesh (.GLB) and a geometrically segmented point cloud (.PLY). Traditional 3D content creation relies on multi-view photogrammetry or manual CAD modeling, creating a high technical barrier for developers and designers. To address this limitation, the proposed system integrates multiple state-of-the-art AI models—including adaptive CLAHE contrast enhancement, automated vision-language captioning via Florence-2, zero-shot object detection using GroundingDINO, pixel-precise SAM 2.1 instance segmentation, background removal via rembg with ONNX Runtime, generative 3D reconstruction using Hunyuan3D-2, and geometric point cloud segmentation through Poisson-disk sampling and DBSCAN clustering—into a unified, prompt-free workflow. Orchestrated by an asynchronous FastAPI backend with sequential GPU VRAM memory management, real-time job status tracking is persisted to a Supabase database while a Next.js frontend delivers interactive 60 FPS 3D WebGL visualization using React Three Fiber. The experimental results demonstrate a fully automated, accessible alternative to traditional photogrammetry, synthesizing production-ready 3D assets directly from a single photograph.
